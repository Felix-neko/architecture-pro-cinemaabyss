# Прокси-сервис

Решил запилить прокси-сервер не велосипедиком на FastAPI, а по-энтерпрайзному: с помощью Kong на минимальных настройках.

К сожалению, Kong оказался слишком энтерпрайзным, и читать переменные среды его бесплатная версия не умеет, поэтому пришлось добавить простенькую шаблонизацию настроек.
